### Recording this version

When copying this project into a website or app, record the project name, copied version, copy date, and any local changes in the consuming project's `REUSABLE-COMPONENTS.md`. This version is not tracked automatically because the project is copied rather than installed as a versioned package.

A structured project-page foundation for consistent portfolio case studies. It provides metadata, role lists, natural inline links, media slots, narrative sections, gallery content, and next-project navigation.

The component intentionally accepts render functions for hero media and galleries so it does not lock projects to a particular image framework.
